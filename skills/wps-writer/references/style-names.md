# WPS 文字样式名

- 中文样式名**带空格**：`"标题 1"`、`"标题 2"`、`"标题 3"`、`"正文"`。
  写成 `"标题1"` 会静默失败或抛异常——这是 WPS 中文版最常见的坑。
- 取样式统一用 `.Item()`：`$doc.Styles.Item("标题 1")`（集合索引从 1 开始）。
- 中文字体必须双设，只设 `Name` 中文会回退到默认字体：
  ```powershell
  $range.Font.Name = "Calibri"       # 西文部分
  $range.Font.NameFarEast = "宋体"   # 中文部分（常用：宋体 / 黑体 / 楷体 / 仿宋）
  ```
